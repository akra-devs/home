Akra MCP Analytics

Read app performance, advertising revenue and campaign results through one internal reporting workflow.

Akra MCP Analytics is a private connector used by AkraDev Studio's owner and authorized internal operators. It connects accounts they are entitled to access to locally installed Model Context Protocol (MCP) servers and Codex, the AI-assisted operator interface. This website explains the connector; it does not offer public registration or access to account data.

What it does

  • Google Analytics: reads authorized account and property information and aggregate app usage reports.
  • AdMob: reads app and ad-unit information, impressions and revenue reports.
  • Google Ads: supports read-only campaign reporting when the separate account authorization and API access approval are in place.

The Google Ads and reporting authorizations are separate. The current MCP tools do not create campaigns, change budgets or place bids. Firebase Crashlytics is connected separately through Firebase authentication and is not authorized by this OAuth client.

How access works

  1. An authorized operator starts the connector on their computer and reviews Google's account and permission screen.
  2. Google grants only the approved access. Credentials stay in the operator's protected local credential directory.
  3. Requested API results are returned to Codex for the operator's report or analysis. The AI provider processes those results under the operator's applicable service settings.

Read the privacy policy for data use, storage, AI processing and revocation, and the terms of use for authorized use.

앱 운영 데이터를 확인하는 내부 도구

Akra MCP Analytics는 AkraDev Studio의 소유자와 권한을 받은 내부 운영자가 사용하는 비공개 연결 도구입니다. 접근 권한이 있는 Google 계정을 로컬 MCP 서버와 Codex에 연결해 보고서와 분석에 사용합니다. 이 웹사이트는 도구를 설명하는 안내 페이지이며 일반인 가입이나 계정 데이터 조회 기능을 제공하지 않습니다.

조회 범위

  • Google Analytics: 계정·속성과 앱 이용 집계 보고서
  • AdMob: 앱·광고 단위 정보, 광고 노출·수익 보고서
  • Google Ads: 별도 계정 인증과 API 접근 승인이 완료된 경우 광고 캠페인 보고서

Ads와 보고서 서비스의 인증은 분리되어 있습니다. 현재 MCP는 캠페인 생성, 예산 변경, 입찰 기능을 제공하지 않습니다. Firebase Crashlytics는 별도 Firebase 인증을 사용합니다.

인증과 데이터 처리

운영자가 자신의 컴퓨터에서 Google 계정과 권한을 확인하고 동의하면, 인증 정보는 접근이 제한된 로컬 폴더에 저장됩니다. 요청한 조회 결과는 보고서 작성을 위해 Codex로 전달되며 AI 서비스의 계정 설정과 정책에 따라 처리됩니다.
