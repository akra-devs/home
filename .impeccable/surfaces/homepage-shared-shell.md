# Homepage and shared shell

Mode: Experience, with a direct consultation action.
Scope: homepage components, shared Navbar/Footer, semantic App hooks and index.css.
World: preserve Akra's blue mark and midnight gallery; quiet tonal hierarchy,
Pretendard Korean UI/headlines, authentic media and readable text.

The first viewport pairs the deliberate idea-to-product slogan with existing
Stillstamp and Key Ddal media. The catalog is the evidence: all 11 entries remain,
each one grid cell, including Waxball. Media is reserved above text, never under
it. Concept/private entries use labeled typographic studies, not stock images,
invented screenshots or links. Preview availability is explicit.

Navigation uses 44px controls, visible focus and a compact menu below 1024px;
Escape/link activation close the panel. It remains scrollable on short phones.
Filter state is native pressed buttons. Reduced motion removes transitions.
Contact's actual action is mailto:help@akra.kr; no inert form or delivery claim.

Acceptance: equal card widths and shared row-height policy, natural Korean at
375px, no sideways overflow, functional destinations and controls at 768px/375px,
no product-page component, media or control changes. Shared CJK wrapping applies
to product headings and Korean paragraphs. Lead owns real-browser evidence and
the final detector.
